# Portfolio — 2019 learning project

I built this site in 2019 for the “Fundamentos del Desarrollo Web” assessment, using HTML, CSS, Bootstrap and JavaScript.

I keep it as part of my learning history. The biography, work history and contact details reflect that time. For my current focus, visit [my GitHub profile](https://github.com/ignaciobriceno).

## Run locally

From the repository root, with Python 3 installed:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Fonts and frontend libraries load from external CDNs.

This learning project is no longer maintained. Historical links and forms may no longer work. No automated tests are included.
